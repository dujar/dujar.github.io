Abstract

I came to code by way of academia: writing a thesis in LATEX sparked a lasting appreciation for the craft. A decade of GitHub later, the work spans declarative UI runtimes, systematic trading engines for on-chain perpetuals, and tooling that lets AI agents carry software from idea to merge — built in Rust and TypeScript, between Singapore and Thailand.
